# Python Script Guidelines

These rules apply to Python scripts generated by agents for this project.

Put Python files inside `src/` under the workspace folder. You may create
multiple files under `src/` as needed. Put all other files inside `raw/`.

Before writing code, ensure the following fields exist in `pyproject.toml`. You
can disable a lint rule by writing it in `ignore`, or use `# type: ignore`
comments to suppress specific type errors when truly necessary.

```toml
[project]
name = <project-name>
version = "0.1.0"
requires-python = ">=3.14"
dependencies = []

[dependency-groups]
dev = ["ruff", "ty"]

[tool.ty.rules]
all = "error"

[tool.ruff]
target-version = "py314"

[tool.ruff.lint]
select = ["ALL"]
ignore = []
```

## File Management

- Use `write_file` to create a new file. Use `edit_file` to improve an existing
  one.
- Edit the file in place. Do not create versioned copies (`_v2`, `_v3`,
  `_final`, `_new`, etc.)

## Code Structure

- Use the `logging` module for output. Do not use `print()`.
- Use `pathlib.Path` for all file and directory path operations.
- Adopt a fail-fast error handling strategy.
- Do not execute logic at module level. Group all behavior into functions and
  classes.
- Always define a global `THREAD_POOL` (`concurrent.futures.ThreadPoolExecutor`)
  at module scope in the entry module.
- Start entry points with `asyncio.run(main())`. Write clear docstrings on every
  public class and function.

## Imports

- Import classes and types directly at module scope (e.g.,
  `from pathlib import Path`).
- Import modules for function calls and use qualified access (e.g.,
  `import asyncio; asyncio.run(...)`).

## Type Safety

- Choose type-safe packages. Install type stubs when available.
- Avoid `pandas`; use `polars` for tabular data.
- Use `NamedTuple` and `Enum` extensively for structured data and domain values.
- Prefer `collections.abc` over the `typing` module for abstract base classes.
- Use built-in generic types (e.g., `list[T]`, `dict[K, V]`, `set[T]`) instead
  of outdated aliases from `typing` (e.g., `typing.List[T]`, `typing.Dict[T]`,
  `typing.Set[T]`).

## Concurrency

- Prefer non-blocking async code. Use `asyncio`.
- When a third-party library has no async API and blocking is unavoidable, run
  it via `asyncio.get_running_loop().run_in_executor(THREAD_POOL, fn, *args)` so
  the event loop is never blocked.

## Memory

- Avoid loading entire datasets into memory.
- Stream data from disk when reading, and write incrementally where possible.

## Constants

- Keep reusable values as global constants using `UPPER_SNAKE_CASE`.
